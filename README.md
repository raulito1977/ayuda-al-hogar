

🛒 Proyecto Marketplace
Un ecosistema completo de Marketplace con pasarela de pagos integrada, gestión de datos en la nube y despliegue automatizado. Este proyecto combina el desarrollo manual y la programación tradicional en local con la optimización de código asistida por múltiples herramientas de Inteligencia Artificial.
🛠️ Arquitectura y Tecnologías de la Plataforma
El núcleo técnico, el código y la infraestructura del proyecto han sido estudiados, picados e integrados manualmente pieza por pieza:
Entorno de Desarrollo Principal: Programado, estructurado y editado localmente por el autor usando Visual Studio Code.
Desarrollo Base y Lógica: Código personalizado implementado a mano en Node.js y JavaScript, utilizando consultas de IA avanzadas (incluyendo Lovable y otros modelos) para la optimización y soluciones de componentes específicos.
Base de Datos y Autenticación: Integración manual de Supabase para la gestión de usuarios y almacenamiento seguro de datos.
Pasarela de Pagos: Configuración completa del flujo transaccional y procesamiento de pagos con Stripe.
Alojamiento y Despliegue (Hosting): Configuración de la infraestructura de producción y despliegue continuo en vercel conectado al repositorio.
Dominio Personalizado: Gestión, configuración de DNS y apuntamiento de servidores en Namecheap.
Control de Versiones: Gestión completa del repositorio mediante Git y GitHub.
🤝 Créditos del Desarrollo
Este proyecto no es una plantilla automática ni ha sido generado por un solo botón. El verdadero valor del Marketplace reside en la programación manual en Visual Studio Code realizada por el autor, quien ha diseñado la lógica en Node.js y ha estructurado la interfaz. Las herramientas de IA (como Lovable y otros asistentes de código) se han utilizado de forma inteligente como soporte técnico para consultar componentes, resolver lógicas específicas y optimizar el flujo de desarrollo, manteniendo el autor el control total de la integración de todos los servicios críticos (Stripe, Supabase, Vercel, Namecheap).
