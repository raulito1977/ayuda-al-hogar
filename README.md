
# 🛒 Proyecto Marketplace

Un ecosistema completo de Marketplace con pasarela de pagos integrada, gestión de datos en la nube y despliegue automatizado. Este proyecto combina el diseño asistido por IA con un desarrollo, configuración y despliegue manual avanzado.

## 🛠️ Arquitectura y Tecnologías de la Plataforma

El núcleo técnico y la infraestructura del proyecto han sido estudiados, configurados e integrados manualmente pieza por pieza:

* **Desarrollo Base:** Configurado e implementado con código personalizado en **Node.js** y JavaScript.
* **Base de Datos y Autenticación:** Integración manual de **Supabase** para la gestión de usuarios y almacenamiento de datos seguro.
* **Pasarela de Pagos (Marketplace):** Configuración completa del flujo transaccional y procesamiento de pagos con **Stripe**.
* **Dominio Personalizado:** Gestión, configuración de DNS y apuntamiento de servidores en **Namecheap**.
* **Alojamiento y Despliegue (Hosting):** Configuración de la infraestructura de producción y despliegue continuo en **Vercel**.
* **Control de Versiones:** Gestión completa del repositorio mediante **Git** y **GitHub**.
* **Entorno de Desarrollo:** Programado y estructurado localmente usando **Visual Studio Code**.
* **Diseño Asistido:** Prototipado y generación de componentes iniciales en **Lovable**.

## 🧠 Créditos del Desarrollo

Este proyecto no es una simple plantilla automática. Aunque **Lovable** ha asistido en la generación de la interfaz y componentes visuales, el verdadero valor del Marketplace reside en la integración manual de servicios críticos (Stripe, Supabase, Vercel, Namecheap) y la lógica de programación en Node.js, diseñada y desarrollada por el autor de este repositorio.
